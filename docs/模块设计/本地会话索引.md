# 本地会话索引

- **模块定位**：只读发现、解析并聚合本机 Claude Code 会话元数据。
- **对应代码**：`src-tauri/src/providers/claude.rs`、`src-tauri/src/message_previews.rs`、`src-tauri/src/catalog.rs`、`src-tauri/src/models.rs`
- **所属里程碑**：[M0](../roadmap.md#m0)
- **当前状态**：进行中
- **最近更新时间**：2026-08-18

## 职责与边界

本模块读取 `%USERPROFILE%\.claude\projects` 下的顶层 JSONL 会话文件，并尝试合并 Microsoft Store 版 Claude Desktop 的 `claude-code-sessions` 索引。索引链路向前端返回标题、路径、时间和统计信息；会话行悬浮 logo 时，另由 `message_previews` 按需读取最近用户消息，不加载完整对话正文。

本模块不修改、迁移、删除或修复 Claude 原始数据，也不读取 Claude API Key。损坏或无法识别的单个文件会被跳过，并在扫描结果中给出汇总警告。

## 结构与数据流

```text
~/.claude/projects/<encoded-project>/<session-id>.jsonl
                                  │
                                  ├─ 流式逐行解析 cwd、timestamp、message、branch、version
                                  │
Claude Desktop 本地 JSON 索引 ────┤─ 合并 title、model、archive、activity
                                  │
                                  └─ 按真实 cwd 分组、按最后活动时间排序
                                                       │
                                                       ▼
                                           Claude SessionSummary
                                                       │
                                                       ▼
                                             统一 SessionCatalog
```

前端启动时立即扫描，之后每 10 秒自动重新扫描磁盘。当前本机 294 个会话、119 个项目的真实测量结果为 5 次扫描 `0.85–1.17 秒`，平均约 `1.03 秒`；按 10 秒周期计算，扫描任务约占 10% 的时间窗口。前端会在扫描进行中跳过下一次定时触发，避免任务重叠；后续规模明显增长时再加入增量缓存。

## 关键决策

1. 项目路径从会话记录的 `cwd` 或 Desktop 索引取得，避免依赖 Claude 对目录名的不可逆编码。
2. 标题优先级为 JSONL 中最后一次有效的用户自定义标题、Desktop 标题、Claude 会话摘要、首条非元数据用户消息、默认标题。
3. JSONL 使用缓冲逐行读取，避免把大对话完整载入内存。
4. Session ID 必须是 UUID；`subagents` 等非主会话文件不会进入目录。
5. Desktop 索引按 `cliSessionId` 合并，重复记录采用 `lastActivityAt` 较新的版本。

## 当前实现

- 提取项目路径、Session ID、创建/活动时间、消息记录数、分支、模型、Claude Code 版本和文件大小。
- 解析 `custom-title` 记录，用户多次改名时采用最后一次有效标题；清空标题后回退到其他来源。
- 读取不同账号/组织目录下的 Desktop 索引，并保留归档状态。
- 对项目和会话进行稳定排序。
- 项目目录不存在时仍显示历史记录，同时标记为不可续接。
- 对解析失败的文件做数量汇总，不向界面暴露原消息内容。
- 由前端定时触发完整扫描；当前扫描链路保持只读，不写入 Claude JSONL 或 Desktop 索引。
- `message_previews` 仅接受 Claude 项目目录内的 `.jsonl`，过滤元消息并按原始顺序返回最近 5 条用户消息，每条最多 240 个字符。

## 验证方式

Claude provider 的 5 项 Rust 单测覆盖：

- 文本内容块提取。
- 标题清理、截断和命令消息过滤。
- 用户自定义标题优先级和多次改名的最后值。
- Desktop 标题优先级。
- JSONL 用户记录中的路径、分支、版本和消息数提取。
- 从临时 Claude 项目目录扫描、分组并生成可续接会话的完整流程。

统一 Rust 测试目前共 19 项，包含 Claude provider、Codex provider、catalog、启动器和消息摘要读取。完整门禁见根目录 `README.md`。模块保持“进行中”，等待人工打开应用核对真实 Claude 会话标题与时间。

## 待扩展项

- 文件系统监听与增量刷新。
- 普通安装版 Claude Desktop 和未来目录结构的自动发现。
- 会话标签、收藏和本地备注，存放在应用自己的数据库中。
- 摘要预览目前只在用户悬浮或聚焦 logo 时读取，限制为最近 5 条用户消息且不持久化；后续可增加明确的隐私开关和可配置条数。
