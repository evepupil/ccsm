# 前端界面与主题

- **模块定位**：CCSM 桌面窗口、导航侧栏、会话工作区与明暗主题。
- **对应代码**：`src/App.tsx`、`src/components/`、`src/assets/`、`src/hooks/`、`src/lib/sessions.ts`、`src/lib/presentation.ts`、`src/lib/theme.ts`、`src/styles/`、`src/styles.css`、`scripts/generate-app-icon.ps1`、`src-tauri/icons/`、`src-tauri/tauri.conf.json`、`src-tauri/capabilities/default.json`；确认原型位于 `docs/prototypes/ccsm-ui-v3/`
- **所属里程碑**：[M2](../roadmap.md#m2)
- **当前状态**：进行中
- **最近更新时间**：2026-08-11

## 职责与边界

把后端 `SessionCatalog` 渲染成可筛选、可续接的桌面界面，管理来源切换、项目选择、搜索、排序、归档、最高权限、继续、分叉、复制和窗口控制。本模块不直接读取会话文件，所有真实数据经 `src/api.ts` 调用 Tauri 命令获得。

## 结构与数据流

```text
WindowTitlebar ── 当前来源 / 拖动 / 最小化 / 最大化 / 关闭

scanSessionCatalog (Tauri)
          │
          ▼
useSessionCatalog ── provider / catalog / selectedProjectId
          │
          ├──► ProjectSidebar
          │       ├── 来源切换 Tabs
          │       ├── 全局搜索 SearchField
          │       ├── 项目 ListBox
          │       └── 扫描按钮与最近扫描时间
          │
          └──► useSessionFilters ──► SessionToolbar
                         │
                         └──► SessionList ──► SessionItem
                                                   │
useSessionLauncher ◄───────────────────────────────┤
          ├──► resumeSession（继续 / 分叉）
          └──► clipboard + HeroUI Toast
```

`App.tsx` 只组装窗口和业务状态。`useSessionCatalog` 管理扫描、来源与项目选择，`useSessionFilters` 管理搜索、排序、归档和最高权限，`useSessionLauncher` 管理继续、分叉、复制与启动锁。`selectedProjectId` 通过 `localStorage` 记忆；`selectVisibleProjects` 与 `selectVisibleSessions` 作为纯函数计算左右两侧数据。

## 关键决策

1. 视觉方向采用 2026-08-10 用户确认的 v3 原型：暗色工具侧栏、浅色主工作区、紧凑控件和连续会话列表。
2. Tauri 主窗口关闭系统装饰，使用 38px 自定义标题栏；窗口按钮调用 `@tauri-apps/api/window`，对应能力在 `src-tauri/capabilities/default.json` 显式授权。
3. 标题栏只显示 CCSM、当前来源和窗口按钮。顶部不显示“本地索引已就绪”、状态圆点或同类说明；扫描反馈集中在侧栏底部。
4. 来源切换与搜索移入侧栏顶部。来源切换同时更新项目和会话，搜索在当前来源的全部项目中执行；从搜索结果选择项目会清空搜索并进入项目。
5. 会话展示改为按“今天 / 昨天 / 本周 / 更早”分组的连续列表。标题排序使用单独的“按标题排序”分组；不再使用后台表格和固定表头。
6. HeroUI 保留在 `Tabs`、`SearchField`、`ListBox`、`Button`、`Spinner` 和 Toast 等需要 React Aria 行为的控件上；窗口层、工具栏和会话行采用语义化 HTML，便于精确还原桌面布局。
7. 样式按职责拆为 `tokens.css`、`base.css`、`window.css`、`sidebar.css`、`sessions.css`，`styles.css` 只负责导入。明暗主题继续由 `useSystemTheme` 驱动 `.dark` class。
8. 所有固定控件和列表列使用稳定尺寸；1180×760 默认窗口显示独立活动时间，1000px 以下隐藏该列并保留核心元数据和操作。
9. 任一会话启动期间锁住全部继续与分叉按钮，防止桌面终端启动过程中重复提交。
10. 项目总数、会话数、扫描时间、权限风险和错误仍保留，因为它们直接影响操作判断；普通成功状态不占用主工作区。
11. Claude Code 与 Codex 的来源身份统一使用本地品牌素材，Tab 和会话行复用同一个 `ProviderLogo` 组件，不依赖运行时网络。应用图标以 Claude Code 图标为主体，右下角叠加 `>_` 会话管理徽标，和官方 Claude 客户端保持可区分性；应用 EXE、NSIS 安装器与卸载器统一使用该图标。

## 当前实现

- **App.tsx**：组合 `WindowTitlebar`、`ProjectSidebar`、`SessionWorkspace` 与三个状态 hook，不再渲染旧 `AppHeader` 和 `StatusBar`。
- **WindowTitlebar.tsx**：品牌与当前来源、拖动区域、双击最大化、最小化、最大化和关闭按钮；普通浏览器预览中窗口动作安全跳过。
- **ProjectSidebar.tsx**：HeroUI `Tabs`、`SearchField`、`ListBox` 和扫描按钮；项目数量与来源、搜索、归档状态联动，底部显示总会话数和扫描时间。
- **SessionToolbar.tsx**：项目标题、路径、结果数、原生排序选择器和两个紧凑开关；900px 最小窗口保持单行工具栏。
- **SessionWorkspace.tsx**：权限提醒、加载、错误、空数据、搜索标签和可滚动会话内容。
- **SessionList.tsx / SessionItem.tsx**：按时间分组会话，展示来源图标、标题、项目上下文、分支、模型、用量、Session ID、活动时间、继续和分叉操作。
- **ProviderLogo.tsx / assets**：集中映射 Claude Code 与 Codex 官方 Windows 客户端素材；来源 Tab、会话行和标题栏不再使用字母或通用占位图标。
- **应用图标**：`scripts/generate-app-icon.ps1` 从 Claude Code 素材生成 1024px Tauri 主图标与 64px 标题栏图标，再由 `pnpm icons:generate` 生成 Tauri 所需的 PNG、ICO 与 ICNS 产物。
- **styles/**：集中维护窗口、侧栏、会话和主题令牌；侧栏固定为开发工具风格，主区按系统明暗主题切换。
- **v3 HTML 原型**：`docs/prototypes/ccsm-ui-v3/index.html` 保留完整模拟数据和交互，用于快速确认设计方向；原型中的顶部索引状态也已同步移除。

## 待扩展项

- 最高权限开关保持 danger 状态和风险提醒；真实最高权限续接仍需用户主动触发。
