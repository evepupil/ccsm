## 职责与边界

把后端 `SessionCatalog` 渲染成可筛选、可续接的桌面界面，管理来源切换、搜索、排序、归档与最高权限开关，以及续接 / 分叉 / 复制交互和全局明暗主题。本模块不直接读取会话文件，所有数据经 `src/api.ts` 调用 Tauri 命令获得。

## 结构与数据流

```text
scanSessionCatalog (Tauri) ──► App 状态 catalog
                                   │
   provider / searchQuery / sort / showArchived / highestPermissions
                                   │
        ┌──────────────────────────┼───────────────────────────┐
        ▼                          ▼                           ▼
   ProjectList (ListBox)    SessionTable (Table)        SessionToolbar
        │                          │                  (Switch / Tabs)
        └──► onSelectProject       ├─► onResume (续接/分叉) ──► resumeSession
                                   └─► onCopyId            ──► toast 反馈
```

`App.tsx` 持有 `catalog / provider / selectedProjectId / searchQuery / sort / showArchived / highestPermissions / loading / launchingKey / error` 状态；`selectedProjectId` 通过 `localStorage` 记忆。`selectVisibleSessions` 负责按当前来源、搜索词、归档与排序筛选会话。`launch` 与 `copySessionId` 的结果通过 HeroUI Toast 反馈。

## 关键决策

1. UI 库选 HeroUI v3（React Aria + Tailwind v4），无 Provider 包裹、compound 组件 API（`Table.Header`、`Tabs.List` 等），契合 React 19。
2. Tailwind v4 经 `@tailwindcss/vite` 接入；`src/styles.css` 只需 `@import "@heroui/styles"`，该包内部已含 `tailwindcss` + base + 默认主题 + utilities，无需自写 `@plugin` 或 `heroui()` 工厂（v3 与 v2 的主要差异）。
3. 品牌色通过覆盖 CSS 变量 `--accent` 实现：`Button variant="primary"` 等强调控件自动跟随，HeroUI 基于 `--accent` 自动 `color-mix` 派生 hover / soft 色，无需逐组件配色。
4. 暗色：`useSystemTheme` hook 监听 `prefers-color-scheme` 给 `<html>` 切 `dark` class；`styles.css` 用 `@custom-variant dark` 让 `dark:` 工具类跟随同一 class，HeroUI 也通过 `.dark` 触发暗色，三者一致。
5. 操作反馈从自渲染 `notice` 浮层改为 HeroUI Toast（`toast.success / toast.danger` 命令式 API，需 `ToastProvider` 包裹）。
6. 原 893 行手写 `styles.css` 全量废弃，布局改用 Tailwind utility；`styles.css` 仅保留 HeroUI 入口、品牌色覆盖、字体 / 尺寸 base 与 dark 变体声明。
7. provider 徽标等少量品牌色用 Tailwind 任意值 + `dark:` 内联，不引入自定义 CSS class，保持全量重写的自洽。

## 当前实现

- **App.tsx**：grid 布局（header 三栏 / workspace 两栏 / footer）；header 用 `Input` 搜索 + `Tabs` 来源切换 + `Button isIconOnly` 刷新；工具栏 `Switch`（最高权限 / 显示归档）+ `Tabs` 排序；权限警告用 `Alert`；致命错误与空态用 `EmptyState`；加载用 `Spinner`。
- **ProjectTree.tsx**：`ListBox` 单选渲染项目，`onAction` 触发选择，`selectedKeys` 同步高亮，保留搜索过滤。
- **SessionTable.tsx**：`Table` 渲染会话；续接 `Button variant="primary"`、分叉 `Button isIconOnly variant="outline"`、复制 `Button isIconOnly variant="ghost"`。
- **main.tsx**：`ToastProvider` 包裹 `App`，`useSystemTheme` 应用主题。
- **lib/theme.ts**：`useSystemTheme` hook。
- 保留全部状态与交互逻辑、`localStorage` 记忆 `selectedProjectId`、`selectVisibleSessions` 筛选排序与 `launchSessionKey` 启动锁。

## 待扩展项

- JS bundle 533KB（gzip 162KB）有 chunk 超 500KB 警告，后续可改按需引入 `@heroui/<组件>` 子包做 tree-shaking 优化。
- 最高权限开关选中色目前跟随 accent，未做 danger 强提示；可后续用 `data-[selected]` 选择器或自定义 Switch 样式。
- HeroUI 主题目前只覆盖 `--accent`；如需更贴近原设计令牌（warning / danger 色阶），可进一步覆盖对应 CSS 变量。
- 表格表头 sticky 在长列表下的边界尚未人工验证。
