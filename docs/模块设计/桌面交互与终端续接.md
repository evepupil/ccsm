# 桌面交互与终端续接

- **模块定位**：提供项目树、会话查找和受控终端续接的桌面操作界面。
- **对应代码**：`src/App.tsx`、`src/components/`、`src-tauri/src/launcher.rs`；M1 扩展见[多源启动与权限模式](多源启动与权限模式.md)
- **所属里程碑**：[M0](../roadmap.md#m0)
- **当前状态**：进行中
- **最近更新时间**：2026-07-27

## 职责与边界

React 界面负责浏览、搜索、筛选、排序和发起续接请求。Rust 启动器重新从本机索引解析 Session ID 和项目目录，再创建新终端。前端不能提交任意目录、可执行文件或命令文本。

应用不接管 Claude 认证。新终端继承当前 Windows 用户环境，Claude CLI 未安装或未登录时在界面预先提示，实际登录和 Gateway 配置仍由 Claude CLI 处理。

## 结构与数据流

```text
启动 / 刷新
    │
    ├─ scan_session_catalog ──> 项目树 + 会话表格
    └─ get_cli_statuses ──────> 双 CLI 状态提示

点击“续接”或“分叉续接”
    │
    └─ resume_session(provider, sessionId, fork, highestPermissions)
           │
           ├─ UUID 校验
           ├─ 重新扫描并解析真实项目目录
           └─ Windows Terminal / PowerShell
                 └─ 固定的 Claude / Codex 续接命令
```

## 关键决策

1. 主界面采用固定项目树和可滚动表格，面向大量会话的重复查找，不使用装饰性卡片布局。
2. 搜索跨项目匹配标题、项目路径、分支、模型和 Session ID；点击项目后回到该项目的完整会话列表。
3. “续接”保持原 Session ID，“分叉续接”通过独立图标按钮提供，避免无意制造重复会话。
4. Windows Terminal 不可用时，退回带独立控制台的 PowerShell。
5. 选中的项目只保存在 WebView 本地存储，不写入 Claude 数据。

## 当前实现

- 可展开项目树及最近六条会话预览。
- 跨项目搜索、按活动时间或标题排序、归档筛选。
- 会话来源、标题、时间、Session ID、消息数或 Token 数、文件大小、分支、模型/版本展示。
- Session ID 复制、原会话续接、分叉续接、项目目录丢失禁用态。
- 扫描、空结果、错误、启动中和操作提示状态。
- 系统浅色/深色主题与 900 × 620 最小窗口约束。

## 验证方式

前端 12 项单测覆盖相对时间、文件大小、搜索规范化、跨项目搜索、归档过滤、provider 过滤、最高权限警告和排序。TypeScript 开启严格模式、未使用变量检查、索引访问检查和可选属性精确检查。

Tauri release 无安装包构建和 `v0.2.0` NSIS 打包均已通过。最终验收还需人工打开 release 应用检查真实数据，并点击会话确认新终端的工作目录和 resume 参数。本次没有自动启动客户端，也没有启动开发服务器。
