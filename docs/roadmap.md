# CCSM Roadmap

项目目标：让本机大量 Claude Code 与 Codex 会话可查、可筛选、可在原项目目录一键续接，同时保持会话文件只读和凭据隔离。

| ----------------- | -------------------------------------------- | ------ | ------------------------------------------ | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="m0"></a>M0 | 完成 Claude 会话索引、桌面浏览与安全续接闭环 | 进行中 | Rust stable MSVC、WebView2、Claude CLI     | [本地会话索引](模块设计/本地会话索引.md)、[桌面交互与终端续接](模块设计/桌面交互与终端续接.md)    | 能扫描真实 Claude 会话；标题与时间正确；搜索和归档筛选可用；原会话与分叉续接能打开新终端；自动化门禁通过；人工确认真实窗口与续接               |
| <a id="m1"></a>M1 | 增加 Codex 索引、双来源合并和最高权限续接    | 进行中 | M0、Codex `state_*.sqlite`、Codex CLI      | [Codex 会话索引](模块设计/Codex会话索引.md)、[多源启动与权限模式](模块设计/多源启动与权限模式.md) | Claude 与 Codex 按项目合并；来源筛选可用；两种 CLI 的续接、分叉和最高权限参数正确；完整门禁与 Windows release 构建通过；人工确认一次双来源续接 |
| <a id="m2"></a>M2 | 建立 HeroUI + 自定义窗口层的桌面 UI 体系     | 进行中 | M0、HeroUI v3、Tailwind v4、Tauri 窗口能力 | [前端界面与主题](模块设计/前端界面与主题.md)                                                      | 无边框窗口、导航侧栏和分组会话列表可用；品牌色与暗色跟随系统；tsc 严格/vitest/vite/Tauri build 通过；默认与最小窗口视觉和交互回归确认          |

当前进度：M0 的 Claude 基础功能已经落地；M1 的 Codex SQLite 只读索引、统一项目树、双 CLI 检测、来源筛选和最高权限启动已实现。格式检查、TypeScript 严格检查、前端 14 项单测、Clippy 零警告、Rust 11 项单测、Vite 生产构建、Tauri release 构建和 NSIS 打包均已通过。`v0.2.0` 产物已生成，剩余退出项为人工打开 release 窗口并各确认一次 Claude 与 Codex 续接。

M2 已按用户确认的 v3 方向完成正式前端迁移：无边框标题栏、暗色导航侧栏、侧栏来源 / 搜索和时间分组会话列表已接回真实 Tauri 数据；顶部索引成功状态已移除，默认尺寸与 900×620 最小窗口视觉回归通过，最高权限真实续接仍保留用户侧主动确认。
