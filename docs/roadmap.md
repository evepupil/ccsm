# Claude Session Manager Roadmap

项目目标：让本机大量 Claude Code 会话可查、可筛选、可在原项目目录一键续接，同时保持会话文件只读和凭据隔离。

| 里程碑            | 目标                                     | 状态   | 依赖                                   | 模块文档                                                                                       | 退出标准                                                                                                                                      |
| ----------------- | ---------------------------------------- | ------ | -------------------------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| <a id="m0"></a>M0 | 完成本机会话索引、桌面浏览与安全续接闭环 | 进行中 | Rust stable MSVC、WebView2、Claude CLI | [本地会话索引](模块设计/本地会话索引.md)、[桌面交互与终端续接](模块设计/桌面交互与终端续接.md) | 能扫描真实会话；标题与时间正确；搜索和归档筛选可用；原会话与分叉续接能打开新终端；前后端测试、静态检查和无安装包构建全部通过；形成 Git commit |

当前进度：M0 的实现已落地；前端格式检查、TypeScript 严格检查、8 项前端单测、Rust 格式检查、Clippy 零警告检查、7 项 Rust 单测、Vite 生产构建和 Tauri release 构建均已通过。剩余退出项为人工打开窗口检查真实数据，并确认一次终端续接。
